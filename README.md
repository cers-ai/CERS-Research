# CERS Academic · 澄思学术

**本地优先的 AI 科研工作台**

CERS Academic 帮助研究者从本地资料和模糊想法出发，逐步明确研究问题，在科研图上组织研究工作，完成文献分析、实验验证与报告编写，并把正式成果持续沉淀到统一的研究资产库。

它不是聊天机器人加一个画布，也不是任务看板或文件管理器。它把对话、交互卡片、科研图、专业工作区和研究成果放在同一个研究工作台里，同时把研究方向、关键决策和成果的控制权保留给研究者。

## 产品定位

以目标研究成果为牵引，以科研图组织研究工作，以节点工作区完成专业任务，以统一研究资产沉淀成果。

推荐使用路径：

打开本地项目 → 理解现有资料 → 与 AI 讨论并确认研究认知 →
锤炼研究选题与定义 → 在画布上组织研究工作 → 在节点中开展研究与实验 →
把成果汇总到报告 → 形成可编辑、可追溯、可导出的正式成果。

这是一条推荐路径，不是强制流程。研究者可以随时跳转、回退、并行开展研究，或新增研究方向。

## 核心能力

### 科研图

- 四类节点：总课题、研究、实验、报告。
- 两种关系：实线箭头表示分解，虚线表示一般研究关联。
- 支持拖动、缩放、选择、连接、位置保存和视口恢复。
- 节点可编辑、删除；删除根节点受保护；支持撤销最近一次创建操作。

### 节点浮动工作区

- 双击节点打开，浮在应用视口之上，不随画布缩放漂移。
- 可移动、调整大小、收起和关闭。
- 研究工作区优先展示专业内容，对话作为协作入口。
- 每个节点拥有独立上下文和对话记录。

### 研究定义与智能分解

- 研究定义是项目、选题页和总课题节点共享的唯一事实源，可随时编辑。
- 智能分解由模型生成候选节点与关系，以可编辑提案呈现。
- 确认前只显示虚线预览，不写入正式科研图；确认后一次性创建。
- 用户可以删除候选、改名、调整类型与关系，或放弃提案。

### 实验节点

- 从项目中选择 CSV/TSV 数据资产，用内置分析计算行数、缺失值、数值统计与相关性。
- 每次运行保留独立记录，可回看历史结果；原始数据文件只读，不被覆盖。
- 不默认执行任意 AI 生成脚本，分析逻辑固定、可复核。

### 报告节点

- Markdown 正文直接编辑，自动保存并保留版本历史。
- 可以从历史版本恢复内容，并导出 Markdown、DOCX 与 PDF。
- 空报告可按研究目标、已收藏来源与本地资料生成提纲，确认后才写入正文。
- 从当前报告节点收藏的来源插入 Markdown 引用，并一键整理参考文献；仅题录/仅摘要会在参考文献中标注。
- AI 修订只返回逐项局部替换建议，展示原文、建议文本与理由，勾选后才写入正文。
- 应用前检查报告版本与原文片段，正文已被改动时拒绝覆盖。

### 研究资产

- 打开本地文件夹即可扫描文件，原始文件保留原位。
- 自动识别文献、数据集、代码、文档、图片等类型。
- 文本类文件建立全文索引，支持中英文内容检索与命中片段高亮。
- PDF（含文本层）与 DOCX 自动提取正文；PDF 检索结果标注命中页码，扫描版 PDF 明确提示缺少文本层。
- 资产详情展示来源、路径、状态、大小、修改时间和正文预览。
- 可把本地文献、文档或数据资产引用到节点；引用只建立关联，不复制原文，对话读取有限摘录。
- 文件被移动或删除时保留索引与关联；删除后显示“源文件不可用”。
- 文件在 Workspace 内移动或改名后，重新扫描会按内容指纹自动重定位，保留原资产 ID 与引用。

### 学术检索与来源

- 内置 OpenAlex、Crossref、arXiv、Semantic Scholar、PubMed、Europe PMC 学术来源。
- 多来源并行检索，统一归一化并按 DOI / 标题去重。
- 明确区分仅题录、仅摘要、已获全文和不可获取，不把摘要当作全文。
- 检索结果可收藏到当前节点，成为可复用的研究来源。
- 对话会参考已收藏来源，并要求模型说明证据覆盖级别，不编造 DOI、页码或实验结果。
- 新闻资讯与学术文献并列检索：RSS/Atom 支持按关键词筛选或读取最新条目，保留原站链接、发布时间与检索时间，转载不视为独立证实。

### 模型与资料来源配置

- 支持自定义 OpenAI-compatible 服务和本地 Ollama 类服务。
- 服务与具体模型分开配置，可分别指定对话、研究、规划、代码和报告角色。
- 支持代理、超时、启用/停用、连通性与真实模型调用测试。
- 学术、新闻与网页来源分组管理，支持 RSS/Atom 订阅。
- API Key 保存在操作系统凭据库，不写入项目文件、日志或导出内容。
- 模型或来源未配置时，本地项目、画布、资产和文档编辑仍然可用。

### 本地优先与数据安全

- 项目以用户选择的本地文件夹为根，配置保存在 `.cers`，内部状态保存在 `.cers-data`。
- 扫描、分类和索引不会移动、复制或覆盖原始文件。
- 外部模型与来源请求遵循用户配置，不静默改变数据外发范围。
- 正式成果保存为真实文件，而不是只能留在应用内的临时内容。
- 可生成包含配置、数据库快照、研究输出与 Workspace 文件的项目备份，并恢复到新的空文件夹。

## 当前版本能力

当前版本已经可以：

- 打开本地研究文件夹并建立项目；
- 扫描资料、浏览统一资产库、全文搜索与预览正文；
- 在科研图上创建和整理四类节点与两类关系；
- 打开节点浮动工作区，与科研伙伴对话；
- 配置模型服务、角色路由、学术来源与 RSS 来源；
- 真实调用 DeepSeek 等兼容模型；
- 多来源检索学术文献，切换资讯模式读取 RSS 新闻并保留原站链接；
- 将检索结果收藏到节点，或把本地资产引用到节点，对话会读取来源元数据与有限正文摘录；
- 编辑研究定义，并在项目概况、选题页与总课题节点共享；
- 解析 PDF 文本层与 DOCX 正文并建立全文索引，检索结果可定位到 PDF 页码；
- 文件在本地移动或改名后按内容指纹自动重定位，不产生重复资产；
- 在实验节点用内置 CSV 分析真实计算统计量与相关性，保留多轮运行记录；
- 在报告节点直接编辑 Markdown 正文，自动保存、恢复历史版本并导出 Markdown；
- 为报告生成可确认的提纲，插入来源引用并整理参考文献，用 AI 生成逐项修改建议；
- 使用智能分解生成可编辑的节点提案，确认后才写入正式科研图；
- 生成一致性项目备份并恢复到新目录，保留节点、来源与报告引用；
- 安装为 Windows 桌面应用，不要求用户安装 Python 或 Node.js。

## 运行环境

- Windows 11 x64（首版优先平台）
- 安装包已包含应用运行所需的本地服务与 Python 运行时
- 如需使用大模型，需在设置中配置可访问的模型服务
- 学术与新闻来源按需配置，未配置时不影响本地功能

## 安装与开始

1. 运行 `CERS-Academic-Setup.exe` 完成安装。
2. 启动 CERS Academic。
3. 选择本地研究文件夹作为项目 Workspace。
4. 在设置中配置模型服务与需要的学术/新闻来源。
5. 进入项目概况、选题研究或科研图开始工作。

## 设计原则

- 研究为主，对话是协作方式。
- 流程提供引导，不强制线性执行。
- 智能分解提出方案，用户确认后才改变科研图。
- 节点表达独立研究工作，节点内部承载具体过程。
- 专业内容占据主体，卡片只在需要决策时出现。
- 正式成果自动沉淀，中间过程按需保留。
- 证据来源可追溯，不把推断当成已验证事实。
- 本地文件是真实来源，AI 负责组织而不是替代。
