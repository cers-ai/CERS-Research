## 5. 当前风险与注意事项

1. **系统 Python 是 3.14.4**：任何直接 `python` 运行的脚本都可能绕过 3.13 锁定。开发时统一用 `uv run`，Sidecar 启动自检版本。
2. **pnpm 未安装**：当前采用 npm workspaces；若团队坚持 pnpm，需要补装并更新 `packageManager` 与文档，不影响契约。
3. **Tauri CLI 已作为 devDependency 安装**：不要另装全局版本，避免 npm 与 cargo 两侧版本不一致。
4. **契约是手写三份**：已有一致性脚本，但 M0 应评估 codegen；在此之前禁止手工改单端。
5. **文档版本引用**：技术方案已从 V1.1 升到 V1.2，团队引用旧版本号视为过期。
6. **未提交的仓库**：当前只有工作区文件；首次提交前需确认 `.gitignore` 不会漏掉密钥或 Workspace 数据。
7. **宿主机提交内存曾不足（已缓解）**：早前 `FreeVirtualMemory` 仅约 17 MB，`uv sync` 以 `STATUS_COMMITMENT_LIMIT (0xc000012d)` 退出；内存恢复后已完整安装成功。若再次出现，先检查是否有大型进程占用提交内存，不要误判为依赖损坏。
8. **Windows venv 解释器可能是启动器**：实测 `.venv/Scripts/python.exe` 会再启动基础解释器，因此停止 Sidecar 必须按进程树终止（已实现 `taskkill /T /F`）。打包版本应使用内置解释器，避免该层启动器。
