### 网络与隐私

- 允许把研究文本/文件发送给已配置的远程模型。
- 不做逐次外发确认。
- 不提供离线模式开关；本地项目、画布、资产与报告不依赖网络。
- 不强制代理；代理地址留空即直连。

## 2. 密钥与配置存储

- 非敏感配置：应用配置目录下的 `settings.json`（按 Tauri `app_config_dir` 定位）。
- 密钥：Windows 凭据管理器，服务名 `chengsi.academic`，条目为 `model:<providerId>`、`source:<sourceId>`。
- Workspace、`.cers`、SQLite、设置文件、日志中不保存明文密钥。
- 页面只显示“已配置/未配置”，不回显密钥。

## 3. 节点对话（已接入）

- 入口：选题页「科研伙伴」，或打开节点浮动工作区 →「科研伙伴」。
- 选题页读取真实模型配置与角色路由；模型可用时直接使用总课题节点对话，不再显示硬编码的“模型尚未配置”。
- 链路：React → Rust 命令 `send_node_message` → Python Sidecar `POST /chat` → DeepSeek → 结果落库。
- 上下文：当前节点类型、标题、目标，以及最近 12 条对话；系统提示明确禁止编造文献、DOI、页码与实验结果。
- 持久化：`conversation` 表按项目/节点隔离保存 user/assistant 消息；重开工作区可恢复。
- 角色：节点对话使用「研究」角色路由；未配置时回退到对话角色或首个可用模型。
- 失败处理：密钥缺失、网络失败、模型错误、空回复都会以可读中文提示返回，不会写入伪造回复。
- 手动烟雾测试：`cargo test real_chat_smoke -- --ignored --nocapture`；实测 `model=deepseek-flash, content=你好`。

## 4. 学术检索（已接入）

- 入口：总课题或研究节点 → 浮动工作区 →「文献检索」。
- 链路：React → Rust `search_academic_sources` → Python Sidecar `POST /sources/search` → 多来源并行检索。
- 已接入 6 个适配器：OpenAlex、Crossref、arXiv、Semantic Scholar、PubMed、Europe PMC。
- 每个来源默认最多 5 条，支持起始/结束年份过滤；单源失败不会导致整体失败。
- 结果归一化：标题、作者、年份、期刊/会议、DOI、链接、摘要、来源与获取时间。
- 去重：优先 DOI，其次规范化标题；合并 `alsoFoundIn` 与更高覆盖级别。
- 覆盖级别仅使用「仅题录 / 仅摘要」；不下载全文，也不把摘要标为全文。
- 界面显示每个来源的成功/失败与条数，可复制引用或链接。
- 实测：6 个来源中 5 个成功（Semantic Scholar 返回 HTTP 429），去重后 15 条结果。
- 尚未实现：Evidence 片段/页码定位、正文引用链、全文下载。

### 4.1 收藏来源与对话引用

- 检索结果可「收藏到节点」。
- 存储：SQLite `source_record` 保存题录/摘要与覆盖级别；`source_node_link` 负责节点关联。
- 去重：优先 DOI，其次规范化标题；重复收藏会合并覆盖级别与摘要，不产生重复记录。
- 工作区显示「已收藏来源」，可移除与当前节点的关联；来源记录仍保留在项目中。
- 节点对话会自动读取已收藏来源，写入系统提示，要求模型只引用这些元数据并说明“仅题录/仅摘要”。
- 已实现命令：`save_academic_source`、`list_saved_sources`、`remove_saved_source`、`delete_saved_source`。
- 单元测试覆盖：同一 DOI 去重、覆盖级别合并、节点关联、移除关联、删除来源。

## 5. 需要你完成的操作

1. 打开应用 → **设置 → 模型服务 → DeepSeek → 配置密钥**。
2. 粘贴 DeepSeek API Key → 保存密钥。
3. 点击 **测试连接**。成功后会显示 HTTP 状态、耗时和模型返回片段。
4. 如需提高学术检索配额：**学术来源 → OpenAlex → 配置密钥**。
5. 填写 Crossref / PubMed 联系邮箱：打开对应来源的“编辑”。
6. 如需第三方新闻检索：**新闻资讯 → SerpAPI / NewsAPI → 配置密钥**。
7. 如网络需要代理：**网络与隐私 → 代理地址**，保存后再测试。
