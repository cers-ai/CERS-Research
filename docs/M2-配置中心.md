### 网络与隐私

- 允许把研究文本/文件发送给已配置的远程模型。
- 不做逐次外发确认。
- 不提供离线模式开关；本地项目、画布、资产与报告不依赖网络。
- 不强制代理；代理地址留空即直连。

## 2. 密钥与配置存储

- 非敏感配置：应用配置目录下的 `settings.json`（按 Tauri `app_config_dir` 定位）。
- 密钥：Windows 凭据管理器，服务名 `chengsi.academic`，条目为 `model:<providerId>`、`source:<sourceId>`。
- Workspace、`.cers`、SQLite、设置文件、日志中不保存明文密钥。
- 页面只显示“已配置/未配置”，不回显密钥。

## 3. 需要你完成的操作

1. 打开应用 → **设置 → 模型服务 → DeepSeek → 配置密钥**。
2. 粘贴 DeepSeek API Key → 保存密钥。
3. 点击 **测试连接**。成功后会显示 HTTP 状态、耗时和模型返回片段。
4. 如需提高学术检索配额：**学术来源 → OpenAlex → 配置密钥**。
5. 填写 Crossref / PubMed 联系邮箱：打开对应来源的“编辑”。
6. 如需第三方新闻检索：**新闻资讯 → SerpAPI / NewsAPI → 配置密钥**。
7. 如网络需要代理：**网络与隐私 → 代理地址**，保存后再测试。
