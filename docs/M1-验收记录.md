## 1. 已交付

### 1.1 文件扫描与资产索引

- Rust `walkdir` 只读扫描，跳过 `.cers-data`、`.git`、`node_modules`、`target`、`dist`、`build`、`.venv`、隐藏文件与 `.cers`。
- 单次最多索引 5000 个文件，最大深度 12；超限时标记 `truncated`，且**不会**把未扫描文件误标为缺失。
- 分类：文献（pdf）、数据集（csv/xlsx/json 等）、代码（py/ts/rs 等）、文档（md/docx 等）、图片、其他。
- 稳定资产 ID（项目 ID + 相对路径的 FNV-1a），同一路径重复扫描更新而不重复插入。
- 扫描后对未再次出现的已索引文件标记 `missing`；原始文件内容与位置不变。
- 统一资产库支持关键词（文件名/路径/类型）与类型筛选，展示大小、修改时间、来源、状态、原始位置。

### 1.2 科研图

- `get_graph`：读取节点、关系与图版本。
- `create_node`：研究/实验/报告三类新节点；可选父节点与关系；位置落库；图版本 +1。
- `move_node`：拖动结束后持久化坐标，不改图版本。
- `create_edge`：分解/关联两种关系；拒绝自环、重复关系、分解环（递归 CTE 检测）。
- React Flow 画布：平移、缩放、节点拖动、选择、双击打开、右侧连接点拖线。
- 选中节点出现“打开 / 编辑 / 添加 / 删除”工具条；未选中不常驻操作按钮。
- 分解关系实线箭头，研究关联虚线；关系类型不只靠颜色区分。
- 节点编辑：修改名称与研究目标；总课题名称与项目名绑定，不允许在此改名。
- 节点删除：总课题根节点不可删除；删除节点会级联移除相关关系，真实文件不受影响。
- 连线删除：点击关系后可删除，确认弹窗明确说明不影响节点与文件。
- 单步撤销：撤销最近一次“新增节点”或“新增关系”，清除对应结构；不实现多层撤销。
- 画布视口持久化：平移/缩放结束后保存 x/y/zoom，重新进入画布时恢复。
- 悬浮节点工作区：视口定位、可拖动、可缩放、可收起/展开、可关闭；展示节点目标、状态、ID 与轻量路径。

### 1.3 内容解析与全文检索

- 文本类文件（txt/md/csv/json/html/常见源码）抽取正文，单文件最多读取 1 MB；HTML 去除标签。
- SQLite FTS5 使用 `trigram` 分词，支持中文与英文子串检索；少于 3 个字符时回退 `LIKE`。
- 搜索命中返回资产与高亮片段，前端分片渲染 `<mark>`，不直接注入 HTML。
- 资产详情可预览已索引正文（最多 4000 字符）；PDF/DOCX 暂未解析，界面明确提示。
- 重新扫描会清理并重建对应资产的全文索引；缺失文件保留索引但显示“源文件不可用”。

## 4. 已知边界

- 文本类文件已抽取正文并进入 FTS5；PDF/DOCX 尚未解析，搜索不覆盖这两种格式的正文。
- 资产库有文本/代码/Markdown/CSV 的纯文本预览；PDF/表格/图片查看器尚未接入。
- 无“设为正式资产/提升中间材料”操作。
- 撤销仅一层且只覆盖“新增节点/新增关系”；删除节点和编辑不可撤销。
- 连线不能改类型；节点不能改类型；重命名只支持名称与目标。
- 视口按项目保存；尚未做多窗口/多视口布局。
- 智能分解（提案层）属于 M3，当前未提供入口。
- 扫描为一次性任务，无可取消/进度事件；超大目录只做截断提示。
- 新增节点成功写入由 Rust 测试覆盖；UI 因 150% DPI 下的自动化坐标限制，仅实机验证了弹窗与校验，未完成自动化点击创建。
