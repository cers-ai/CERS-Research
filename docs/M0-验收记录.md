# M0 验收记录（第一个纵向切片）

> 日期：2026-10-29  
> 环境：Windows 10.0.19045 x64；Node 22.22.3；Rust 1.95.0；CPython 3.13.3（uv）；Tauri 2.12.5  
> 结论：**M0 核心链路通过**；MSI 受 WiX 下载阻塞，NSIS 已通过。

## 1. 已交付能力

- 打开本地 Workspace，创建 `.cers`、`.cers-data/`、`Research Outputs/`。
- SQLite schema v1（project/node/edge/proposal/asset/job/job_event），WAL、外键、单根节点唯一索引。
- 重复打开不重复创建项目或根节点；未知 schema 版本明确拒绝。
- Python 3.13 Sidecar 常驻进程：回环 HTTP、每进程随机令牌（环境变量）、stdout 握手、`/health`、`/shutdown`。
- Rust 监管：启动、健康检查、异常退出自动重启、退出清理、Windows 进程树终止。
- Sidecar 可用 PyInstaller 打包为独立 exe，并作为 Tauri 资源进入安装包。
- 桌面 UI：AppShell、项目概况空态/已打开态、画布根节点、资产空态、设置页真实运行时状态。

## 3. 安装包验证（NSIS）

1. 静默安装到 `%TEMP%\cers-install-test`，退出码 0。
2. 安装目录包含：
   - `chengsi-desktop.exe`（11.2 MB）
   - `sidecar\chengsi-worker.exe`（8.46 MB）
   - `uninstall.exe`
3. 启动安装版后：
   - `chengsi-worker.exe --serve` 由应用拉起，未使用系统 Python 或 venv；
   - Sidecar 仅监听 `127.0.0.1` 动态端口；
   - 应用进程与 Sidecar 进程父子关系正确。
4. 关闭应用后：桌面进程与 Sidecar 进程均退出，无残留。
5. 静默卸载后：安装目录被删除。

## 4. 已知问题与边界

- **MSI 未产出**：WiX 3.14 下载在当前网络下长时间无进展，已取消；NSIS 已完成同等安装验证。后续可重试 MSI 或使用已缓存 WiX。
- **UI 层崩溃注入未自动化**：目前由 Rust 测试验证 Sidecar 被杀后自动重启；尚未加入 Playwright/Tauri E2E。
- **Sidecar 只有健康与关闭端点**：任务执行、流式事件、研究工具尚未实现。
- **文件扫描、四类节点交互、智能分解、浮动工作区** 仍属于 M1。
- 安装包未签名，Windows Defender/SmartScreen 提示待评估。
- 开发环境 token 之前曾通过命令行传递，现已改为 `CERS_SIDECAR_TOKEN` 环境变量；旧进程已清理。
